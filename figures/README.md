# GridPulse figures

README figures are code-derived analytical evidence.

## Real PJM EIA-930 figures

The repository now commits three figures generated from the frozen 2022–2025 PJM EIA-930 snapshot after all eight source CSVs were verified against `DATASET_MANIFEST.md`:

- `pjm_2025_peak_demand_forecast.svg` — actual PJM demand, EIA day-ahead forecast, and the GridPulse ML-corrected EIA forecast around the 2025 annual peak,
- `pjm_2025_forecast_benchmark.svg` — 2025 all-hour and top-decile-demand MAE for EIA, same-hour-last-week, and GridPulse ML on identical scoring rows,
- `pjm_2025_june_generation_mix.svg` — reported PJM generation mix during June 2025.

They are regenerated by `scripts/generate_readme_figures.py` from the prepared local Parquet tables. Legends are deliberately placed outside the plotting field and SVGs use constrained/tight layout to avoid label collisions.

## Development fixtures

The older synthetic fixtures remain in the repository as clearly labeled development/test artifacts:

- `demo_demand_forecast.svg`
- `demo_stress_timeline.svg`

They are no longer the primary README evidence and should not be interpreted as real EIA results.
